Политика конфиденциальности

Действует с 14.07.2026

Настоящая политика описывает, как приложение «Дыхание движения» (далее — «Приложение»), которым управляет Сергей Борулько (Санкт-Петербург, контакт: @baguazhangspb), обрабатывает данные при использовании YouTube Data API и Telegram/VK-ботов, обслуживающих канал и сообщество «Дыхание движения» (оздоровительный цигун и ушу).

1. Данные Google/YouTube

Приложение используется одним оператором (владельцем канала «Дыхание движения» на YouTube) для управления собственным каналом. Приложение не запрашивает и не получает доступ к данным других пользователей YouTube — только к каналу, владелец которого лично прошёл авторизацию OAuth.

Через YouTube Data API Приложение получает и обрабатывает следующие данные, ограниченные разрешениями, которые владелец канала явно предоставляет при авторизации:

  • Загрузка и публикация видео (youtube.upload) — Приложение загружает подготовленные видеоролики (сценарий, заголовок, описание, теги, превью) на канал по запросу владельца.
  • Просмотр данных канала (youtube.readonly) — название канала, число подписчиков, просмотры, список видео — для отображения статистики владельцу.
  • Аналитика (yt-analytics.readonly) — агрегированная статистика просмотров/лайков для формирования отчётов и рекомендаций владельцу канала.
  • Правка уже опубликованных видео (youtube.force-ssl) — изменение названия, описания и превью существующих видео канала, добавление видео в плейлисты, по прямому запросу владельца.

2. Как хранятся данные

OAuth-токены (access token и refresh token) хранятся в приватной базе данных (Neon PostgreSQL), доступ к которой имеет только сам оператор Приложения. Токены используются исключительно для автоматического продления сессии между API-запросами и никогда не передаются третьим лицам.

3. Отзыв доступа

Владелец канала может в любой момент отозвать доступ Приложения к своему Google-аккаунту через Google Account → Security → Third-party access. После отзыва все сохранённые токены становятся недействительными; по запросу они также удаляются из базы данных Приложения.

4. Другие данные, которые собирает Приложение

Отдельно от YouTube-интеграции, Telegram- и VK-боты «Дыхание движения» (чат-бот «Конфуций») в рамках своей работы сохраняют:

  • имя и телефон — только если пользователь сам оставляет заявку на запись на занятие;
  • историю переписки с чат-ботом — для того, чтобы бот помнил контекст диалога между сессиями.

Эти данные не связаны с YouTube-интеграцией и не передаются в Google/YouTube API.
