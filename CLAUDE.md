# CLAUDE.md

Руководство по кодовой базе для Claude Code. Актуально на **04.07.2026**.

## Что это

Бот-система для Telegram-канала и группы ВКонтакте, посвящённых **оздоровительному цигун и ушу** (@baguazhangspb, Санкт-Петербург). Ведёт канал и проводит занятия **Сергей** (ID 915727236).
Деплой: **Railway** (проект `distinguished-surprise`, автодеплой при пуше в `main`).
База данных: **Neon PostgreSQL** (отдельная от stremlenie_bot).

## Команды

```bash
pip install -r requirements.txt   # установка зависимостей
python run_all.py                  # локальный запуск всех сервисов
python bot.py                      # только клиентский Telegram (Конфуций)
python admin_bot.py                # только админ Telegram
python vk_bot.py                   # только VK (Конфуций)
```

## Архитектура

### Четыре сервиса в одном процессе

`run_all.py` запускает всё параллельно через `asyncio.gather`:
1. **dashboard** — FastAPI на порту `$PORT` (Railway ждёт открытый порт)
2. **admin_bot.py** — Telegram-бот для Сергея (посты, Reels, контент-план)
3. **bot.py** — Telegram-бот Конфуций для клиентов
4. **vk_bot.py** — VK-бот Конфуций для клиентов

### Чат-бот Конфуций

Персонаж — Конфуций, наставник по оздоровительному цигун и ушу. Отвечает на вопросы о практике, ТКМ, расписании и записи на занятия.

**Где работает:**
- Telegram личка — полный диалог с кнопками меню
- Telegram группа (@baguazhangspb) — на любое сообщение от живого пользователя отвечает «Отвечу подробнее в личных сообщениях» + кнопка-ссылка в приватный чат. Бот должен быть **администратором** группы.
- VK — полный диалог в личных сообщениях группы

**База знаний (`data/knowledge.py → CONFUCIUS_PROMPT`):**
- Официальные программы цигун: Бадуаньцзин, У Цинь Си (五禽戏), И Цзинь Цзин, Да У (大舞), Даоинь
- ТКМ: 12 меридианов, 5 элементов, 10 ключевых точек самомассажа
- Анатомия и физиология цигун
- Стиль Багуачжан и Тайцзицюань
- Ссылки: Boosty (https://boosty.to/s.borulko), VK Донат (https://vk.com/donut/club162151764)

**Шесть целительных звуков (六字诀) в программу НЕ входят — Конфуций их не упоминает.**

### Агент-система (agents/base_agent.py)

`BaseAgent` хранит историю диалога (max 20 сообщений) на каждого `user_id`.

**Персистентная история (переживает рестарты Railway):** `ensure_loaded(user_id)` при первом обращении подгружает историю из таблицы `chat_history` (`data/database.py: load_chat_history`); после каждого ответа агента `_persist(user_id)` сохраняет её обратно (`save_chat_history`, upsert по `(user_id, source)`). Ключ источника (`source`) — `"telegram"` или `"vk"`, задаётся при создании `BaseAgent`.

**Приоритет провайдеров AI:**
1. **Claude Haiku** (`claude-haiku-4-5-20251001`) — основной. Требует `ANTHROPIC_API_KEY`.
2. **OpenRouter** (`google/gemma-2-27b-it:free` → `meta-llama/llama-3.3-70b-instruct:free`) — резерв.
3. **Groq** (`llama-3.3-70b-versatile` → `llama-3.1-8b-instant`) — финальный резерв.

**Постобработка (`_postprocess`):** снимает все `*` и `**` из ответов всех провайдеров, чтобы ссылки и текст приходили без markdown-звёздочек.

**Расписание:** если в запросе ключевые слова («расписани», «занятия», «когда» и др.) — автоматически подгружается расписание из Mobifitness API (клуб ID `2391` — тот же клуб, что у stremlenie_bot; Сергей Борулько ведёт «Оздоровительный цигун» в нём наряду с занятиями студии «Стремление», фильтруется по `TRAINER_FILTER = "Сергей"`): текущая + следующая неделя.

### Флоу записи клиента (bot.py и vk_bot.py)

1. Клиент пишет ключевое слово («записаться», «хочу попасть» и др.)
2. Конфуций спрашивает имя → телефон
3. Заявка сохраняется в БД через `asyncio.to_thread` (не блокирует event loop)
4. Уведомление Сергею через `ADMIN_BOT_TOKEN`
5. Подтверждение: «Записал вас, {name}. Сергей свяжется с вами в ближайшее время.»

### Telegram-бот клиентский (bot.py)

- `/start` — приветствие + главное меню с тремя кнопками
- Кнопка «Подписные площадки» — две URL-кнопки: Boosty и VK Донат
- В личке — полный диалог + кнопки меню после каждого ответа
- В группе — любое сообщение → редирект в личку

### VK-бот (vk_bot.py)

- Long Poll API v5.131
- Получает личные сообщения группы club162151764
- Тот же флоу: диалог с Конфуцием + запись
- `_poll()` с защитой от `failed` и API-ошибок, рестарт при сбое

### Генерация постов и Reels (admin_bot.py + py_render.py)

Аналогична stremlenie_bot. Отличие: `TG_CHANNEL = "@baguazhangspb"`, `VK_GROUP_ID = "162151764"`.
Медиа (видео, аудио, логотип) хранятся в Neon PostgreSQL (BYTEA) и восстанавливаются при рестарте Railway.

### Просмотр диалогов клиентов (admin_bot.py)

Меню «💬 Диалоги клиентов» — т.к. в Telegram (в отличие от VK) у админа нет встроенного способа посмотреть переписку бота с клиентом.
`_render_dialogs_menu()` показывает последние 15 диалогов (`get_recent_chat_histories`, сортировка по `updated_at`): платформа (TG/VK), `user_id`, время последнего сообщения (МСК), превью последней реплики клиента. Список кладётся в `USER_GENERATED[uid]["dlg_list"]`, выбор диалога (`dlg_view_{idx}`) подгружает полную историю (`load_chat_history`) и присылает её админу, разбивая на сообщения по 3800 символов при необходимости.

### Dashboard (dashboard.py)

FastAPI, HTTP Basic Auth. Логин: `$DASHBOARD_USERNAME` (дефолт: `admin`), пароль: `$DASHBOARD_PASSWORD` (дефолт: `qigong`).
Показывает: запланированные посты, историю постов, ссылки на подписки.

## Важные детали

### Комплексы цигун в программе
Бадуаньцзин, У Цинь Си (五禽戏), И Цзинь Цзин, Да У (大舞), Даоинь (导引养生功, Пекинский спортивный университет).
**Шесть целительных звуков не преподаются** — запрещено упоминать как часть программы.

### Стиль ответов Конфуция
- Активный залог, конкретика, 2–4 предложения
- Запрещены: «Отлично!», «Конечно!», «Рад помочь», пересказ вопроса
- Запрещены списки 5+ пунктов без необходимости
- Нет пассивного залога там, где можно сказать прямо

### VK Long Poll
Нужно включить в настройках группы ВКонтакте: Управление → Работа с API → Long Poll API → Версия 5.131 → Входящие сообщения.

### Telegram группа
Бот должен быть администратором группы, чтобы получать все сообщения (не только команды и упоминания).

### Токены с пробелами
Railway иногда добавляет невидимые символы. Все токены читаются с `.strip()`.

## Стратегия роста — «Бадуаньцзин за 21 день»

Флагманский цифровой продукт внутри уже существующего Boosty (не новый сервис — структурирование того, что уже есть). Работаем по этому плану поэтапно, отмечая прогресс.

**Реальный прогресс отмечается в самом боте**, не в чекбоксах ниже: меню «Стратегия роста» в admin_bot.py хранит подробный чек-лист по пунктам в таблице `growth_tasks` (с сохранением состояния между рестартами и ежедневным напоминанием админу о следующей невыполненной задаче после 10:00 МСК). Чекбоксы недель 1–4 в этом файле — только справочная канва плана, актуальный статус смотри в самом боте.

### Идея
21-дневная программа на Boosty: 8 упражнений Бадуаньцзин + дыхательная техника, с прогрессией по дням. Материал уже частично готов — в контент-плане есть темы «Полный комплекс Бадуаньцзинь — 8 упражнений», «Как правильно дышать в цигун». Техническая база по каждому упражнению (повторения, ключевые моменты, частые ошибки) — в `data/knowledge.py → BADUANJIN_TECHNIQUE`, переиспользуется и в промпте Конфуция, и в сценариях YouTube.

### 30-дневный план запуска
- [ ] **Неделя 1 — сборка**: структурировать видео в 21-дневную прогрессию, снять недостающее, собрать PDF-схему движений
- [ ] **Неделя 2 — мягкий запуск**: сообщить текущим подписчикам Boosty, пост в VK/TG от Сергея лично, сообщение через Конфуция тем, кто интересовался практикой
- [ ] **Неделя 3 — публичный запуск**: серия YouTube Shorts-тизеров (по одному упражнению на ролик, CTA на Boosty — ссылка уже подтягивается в описание автоматически), пост с первыми отзывами
- [ ] **Неделя 4 — закрытие когорты**: живой Q&A с Сергеем, бесплатное очное занятие в клубе по итогам, решение — повторять когортами или сделать вечный доступ

### Оффер
- **Название:** «Бадуаньцзин за 21 день»
- **Ядро:** 21 видео-занятие с прогрессией, записаны Сергеем лично
- **Бонусы:** PDF-схема 8 движений, закрытый чат с тренером на время программы, одно бесплатное очное занятие в клубе
- **Гарантия:** возврат в течение 7 дней
- **Дефицит:** живой Q&A только для первой когорты — ограничено временем Сергея (реальный, не фейковый лимит)
- **Цена:** ориентир 1 490 руб. разово, либо Boosty-тир ~690 руб./мес с доступом ко всей библиотеке

### Плейбук первых 100 клиентов (органика, без бюджета)
1. Прямое сообщение текущим подписчикам Boosty
2. Догрев тех, кто писал Конфуцию, но не записался (история диалога теперь персистентна — легко найти)
3. YouTube Shorts-тизеры с CTA на Boosty
4. Пост от Сергея лично в VK/TG
5. Реферал для клиентов клуба — «приведи друга, бесплатное занятие»
6. Win-back по «зависшим» заявкам из `bookings`
7. Бартер с локальными блогерами про ТКМ/оздоровление
8. Комментарии-ценность в тематических пабликах про цигун/ушу
9. Личные сообщения активным подписчикам паблика
10. Кросс-промо со студией «Стремление» — общий клуб, общая аудитория, разные направления

### Двигатель роста дохода
1. **Автодогон после бесплатного взаимодействия с Конфуцием** — персистентная история диалога уже реализована, плюс есть просмотр диалогов в админ-боте для ручного поиска «зависших» клиентов — техническая база для автодогона готова, сам автодогон (авто-сообщение через N дней тишины) ещё не написан
2. **YouTube → Boosty воронка через сам сценарий**, не только описание — CTA должен явно звучать в самом ролике
3. **Win-back по базе `bookings`**
4. **Когортный запуск вместо вечного доступа** — настоящий дефицит, регулярные всплески выручки
5. **Кросс-промо между «Стремлением» и цигун** — общий физический клуб, разные направления

## Предложения по улучшению

1. **OPENROUTER_API_KEY пустой** — генерация постов работает только через Claude; добавить ключ в Railway
2. **GROQ_API_KEY не задан** — финальный резерв AI не работает
3. **Webhook Tilda** — нет endpoint для приёма заявок с сайта (в отличие от stremlenie_bot)
4. **Scheduling для Reels** — Reels публикуются только немедленно; добавить отложенную публикацию
5. **Возвращающийся клиент** — при записи не проверяется история в БД; новый клиент всегда проходит полный флоу
